這些數字怎麼看？

把事實與推論分開
資料事實

例如：「某股票今日收盤價為 100 元，漲跌價差為 +2 元。」這是對來源資料的描述。

可能解讀

例如：「今天收盤價上漲，代表收盤價比前一交易日高。」這只描述價格變化，不代表公司基本面一定變好。

仍不確定

單日上漲不能單獨證明某則新聞造成上漲，也不能確定明天會漲或跌。

白話小教室

常見名詞速讀
收盤價

當天交易結束時的收盤價格。

漲跌價差

與前一交易日收盤價相比，價格增加或減少多少元；不是百分比。

成交股數

當日成交的股票股數，不等於成交金額，也不等於買進的人數。

上市與上櫃

是不同的交易市場。本版本目前只抓取上市股票，不能代表完整的上市櫃市場。

資料來源、更新方式與限制

讓讀者知道數字從哪裡來
  • 來源：臺灣證券交易所 OpenAPI 的上市股票日行情端點。
  • 更新：GitHub Actions 在雲端排程抓取資料並提交網站資料檔。排程可能延遲，不保證精準在某分鐘更新。
  • 資料日期：依 API 回傳日期判斷；遇到週末、休市或來源尚未更新時，資料日期可能不是當天。
  • 歷史紀錄：從啟用自動更新後逐日累積，不會自動補齊上線前所有歷史資料。
  • 目前範圍：上市股票日行情；暫不包含上櫃行情、加權指數歷史圖、股利調整、財報分析或即時報價。

若資料載入失敗，請稍後重試並查看 GitHub Actions 執行紀錄。不要把缺漏資料當成零，也不要把舊資料當成最新行情。
